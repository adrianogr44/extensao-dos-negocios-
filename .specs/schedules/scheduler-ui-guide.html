🔄 Fluxos de Usuário

1. Conectar Conta Meta

1
Usuário clica "Conectar Facebook/Instagram"
↓
2
Redirecionado para OAuth dialog (Meta)
↓
3
Usuário autoriza e retorna ao app
↓
4
Badge "Conectado" aparece com nome da página

2. Agendar Publicação

1
Abrir vídeo → Clique "Publicar nas redes"
↓
2
Modal/página com formulário de agendamento
↓
3
Preencher: descrição, hashtags, plataformas, data/hora
↓
4
Clique "Agendar" → loading spinner + confirmação
↓
5
Toast: "Agendado com sucesso para 15 ago, 14:30"

3. Reutilizar Template

1
Preencher formulário com descrição + hashtags
↓
2
Marcar: "Salvar como template"
↓
3
Nomear template: "Dica de Fitness"
↓
4
Próxima publicação → dropdown "Usar Template" → preenchimento automático

♿ Acessibilidade

WCAG AAA Compliance Checklist
  • Contraste de cores: 4.5:1 mínimo para textos primários
  • Focus rings: Visíveis em todos elementos interativos
  • Navegação por teclado: Tab order segue visual order
  • ARIA labels: Buttons, inputs e regiões bem descritos
  • Form labels: Todos inputs associados a labels (não placeholder-only)
  • Error messages: Usando role="alert" e aria-invalid
  • Dark mode: Testado independentemente em ambos temas
  • Reduced motion: Respeita prefers-reduced-motion
  • Touch targets: Mínimo 44×44px para elementos interativos
  • Screen readers: Meaningful alt text e accessibility announcements

✨ Animation Specifications

Micro-interactions
Duration: 150-200ms
Easing: ease-out
Examples:
• Button hover/active states
• Input focus rings
• Card elevation on hover
State Transitions
Duration: 200-300ms
Easing: ease-out
Examples:
• Form submission (loading → success)
• Modal fade in/out
• Tab/accordion open/close
Loading States
Spinner: rotate 360°
Duration: 1s (continuous)
Button: Disabled + spinner icon
Toast: Auto-dismiss 3-5s
❌ Anti-patterns
• Avoid animations > 500ms
• No decorative-only animations
• Don't animate width/height
• Respect prefers-reduced-motion
• Don't block user input during animation

✅ Pre-Delivery Checklist

Before Shipping
  • All buttons have visible focus rings
  • All form fields have labels + error messages
  • Touch targets ≥44×44px minimum
  • No emojis as icons (use Heroicons/Lucide SVG)
  • Dark mode tested independently
  • Animations respect prefers-reduced-motion
  • Loading states show spinner + disabled button
  • Success/error toasts auto-dismiss in 3-5s
  • Form state preserved on page reload
  • All links/buttons keyboard-accessible
  • Tested on mobile (375px), tablet (768px), desktop (1440px)
  • Landscape orientation tested
  • Color contrast verified with WebAIM
  • Screen reader tested (NVDA/JAWS/VoiceOver)
