# /ars:help — Ajuda do Ars Contexta

Mostra ajuda contextual sobre o sistema Ars Contexta.

## Modos

- **Sem argumentos:** Visão geral + comandos disponíveis
- **`/ars:help setup`** — Ajuda detalhada do setup
- **`/ars:help ask`** — Como usar a base de conhecimento
- **`/ars:help --compact`** — Versão resumida

## Estado do Vault

Se existir um vault, detecte:
- `vault/notes/` — contagem de notas
- `vault/ops/derivation-manifest.md` — configuração atual
- `vault/ops/health/` — warnings de saúde
