# /ars:ask — Consultar Base de Conhecimento

Responda perguntas sobre a metodologia Ars Contexta usando a base de pesquisa em `.opencode/references/arscontexta/`.

## Fluxo

1. Classifique a pergunta:
   - **WHY** → Pesquise em `methodology/` (claims de pesquisa)
   - **HOW** → Leia guias em `reference/`
   - **WHAT** → Exemplos de domínio em `use-case-presets.md`

2. Busque na base de conhecimento usando Grep/Glob

3. Sintetize uma resposta fundamentada nos claims

4. Cite as fontes específicas

## Dicas

- Para perguntas conceituais, use `methodology/` — cada arquivo é um claim de pesquisa
- Para implementação, leia `reference/kernel.yaml` e `reference/three-spaces.md`
- Para casos de uso, veja `reference/use-case-presets.md`
